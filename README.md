# IPTV Ultra Pro — Android & Android TV Player

Полнофункциональный нативный IPTV-плеер на Kotlin, Jetpack Compose, Room и AndroidX Media3 (ExoPlayer).

## Ключевые возможности (превосходящие IPTV Pro)
1. **Все форматы плейлистов:** M3U / M3U8 по ссылке, локальные файлы из памяти устройства, авторизация **Xtream Codes API**.
2. **Потоковый парсер без OutOfMemory:** Мгновенная загрузка списков на 20 000+ каналов с сохранением в базу данных Room.
3. **Телепрограмма (XMLTV EPG) и Архивы (Catch-up):** Автоматическая распаковка `.xml.gz`, поддержка протоколов архивов `flussonic`, `shift`, `xc` и пользовательских шаблонов.
4. **Мультискрин (до 4 каналов одновременно):** Просмотр до 4 прямых эфиров на одном экране с переключением активного звука по нажатию.
5. **Продвинутый плеер Media3:**
   - Умный автореконнект при потере пакетов и обрыве сети.
   - Настройка размера буфера (от 5 до 60 сек).
   - Жесты: свайп слева — яркость, свайп справа — громкость, двойной тап — переключение соотношения сторон (16:9 / Растянуть / Зум).
   - Выбор звуковых дорожек и субтитров.
   - Режим «Картинка в картинке» (PiP).
6. **Сетевые инструменты и защита:**
   - Поддержка UDP-прокси (`udpxy`) для мультикаст-потоков.
   - Глобальный и индивидуальный (`#EXTVLCOPT`) `User-Agent` и `Referer`.
   - Фоновый **Health Check** — автоматическая проверка рабочих потоков и скрытие мертвых каналов в 1 клик.
   - Родительский контроль (PIN-код на категории 18+).
7. **Универсальный интерфейс (Смартфон + Android TV):** Поддержка сенсорного управления, крестовины пульта ДУ (D-pad focus) и баннера для лаунчера Android TV.

## Как собрать готовый APK через GitHub за 3 минуты
1. Создайте новый пустой репозиторий на [github.com](https://github.com).
2. Загрузите в него все файлы из этого архива (сохраняя структуру папок, включая скрытую папку `.github`).
3. Перейдите во вкладку **Actions** вашего репозитория -> выберите **Build IPTV Ultra Pro APK** -> дождитесь зеленой галочки и скачайте готовый `app-debug.apk` из раздела **Artifacts**.
